# AI Agent для Windows (Gemini)

Простой AI-агент с окном на tkinter. Общается через Google Gemini, умеет создавать, читать и запускать файлы в своей рабочей папке: скрипты `.py`, `.bat`, `.ps1`, `.js`, `.vbs`.

## Скачать готовый ИИ-АГЕНТ: (Windows)

**Готовый файл без установки Python для сборки:** скачай `app.exe` на странице [Releases](https://github.com/pavekscb/agent/releases/latest).

## Возможности

- Создание, чтение и запуск файлов в папке `workspace`
- Резервные модели: если одна занята, ответит следующая
- Ввод API-ключа прямо в программе (в коде ключа нет)
- Счётчик запросов за день в процентах
- Подтверждение записи и запуска файлов, с защитой от опасного кода
- Копирование и вставка на любой раскладке (правый клик и Ctrl+C/V/X/A)
- История переписки сохраняется между запусками

## Что нужно

- Windows 10 или 11
- Python 3.10 или новее с [python.org](https://www.python.org/downloads/). При установке **обязательно отметь галочку "Add Python to PATH"**. Версия из Microsoft Store не подойдёт
- Бесплатный API-ключ Google Gemini

## Установка

1. Скачай файл `app.py` из этого репозитория (кнопка **Code → Download ZIP** или открой файл и нажми **Download raw file**).
2. Положи его в отдельную папку, например `C:\Users\ИМЯ\youtube_agent\`.
3. Открой командную строку (`Win + R`, введи `cmd`, Enter) и установи библиотеку:

```
pip install google-genai
```

## Получение API-ключа

1. Открой [Google AI Studio](https://aistudio.google.com/apikey) и войди в аккаунт Google.
2. Нажми **Create API key** и выбери проект (или создай новый).
3. Скопируй ключ (начинается с `AIza...`). Никому его не показывай.

## Запуск

В командной строке перейди в папку с файлом и запусти:

```
cd C:\Users\ИМЯ\youtube_agent
python app.py
```

При первом запуске окно для ввода ключа откроется само. Вставь ключ (правый клик или Ctrl+V) и нажми **Сохранить**. Ключ запишется в `agent_config.json` рядом с программой, повторно вводить не нужно. Заменить его можно кнопкой **Ввести ключ**.

Рядом с `app.py` программа сама создаст:

- `workspace\` — рабочая папка агента (кнопка **Папка** открывает её)
- `agent_config.json` — настройки, ключ и счётчик запросов
- `history.json` — история переписки

## Сборка в exe (необязательно)

Чтобы запускать двойным кликом без командной строки:

```
pip install pyinstaller pillow
python -c "from PIL import Image; Image.open('icon.png').save('icon.ico')"
python -m PyInstaller --noconsole --onefile --icon=icon.ico app.py
```

(Нужен файл `icon.png`; без значка команду можно упростить до `python -m PyInstaller --noconsole --onefile app.py`.)

Готовый `app.exe` появится в папке `dist`. **Скопируй его в отдельную папку**, например `C:\Users\ИМЯ\youtube_agent\`, и запускай оттуда: рабочая папка, история и настройки создаются рядом с exe.

> Для запуска скриптов из exe на компьютере всё равно нужен установленный Python.

## Как пользоваться

Пиши агенту обычным языком:

- «Создай файл hello.py, который выводит hello world, и запусти его»
- «Покажи файлы в рабочей папке»
- «Нарисуй анимацию вращающегося квадрата и запусти её в отдельном окне»

Перед записью и запуском файлов появится окно подтверждения. Галочка **«Без всплывающих окон»** отключает его, но для опасного кода (удаление файлов, `subprocess`, реестр и т.п.) подтверждение спрашивается всегда.

## Лимиты

Счётчик вверху показывает запросы за день для текущей модели. Лимит в программе по умолчанию 500 в день (бесплатный тариф). Если Google изменит лимиты, поправь словарь `DAILY_LIMITS` в начале `app.py`. Точные цифры смотри по кнопке **Квоты**. Счётчик считает только запросы из этой программы.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `'pip' is not recognized` | Переустанови Python с галочкой "Add Python to PATH" |
| «Python не найден в системе» при запуске скрипта из exe | Установи Python с python.org (не из Microsoft Store) |
| Ошибка про API key | Нажми **Ввести ключ** и вставь ключ заново |
| Ошибка 429 или «занята» | Исчерпан лимит запросов, подожди или проверь **Квоты** |
| Ошибка 404 / модель не найдена | Названия моделей могут меняться. Обнови список `MODELS` в начале `app.py` по [документации Gemini](https://ai.google.dev/gemini-api/docs/models) |
| Скрипт с картинками не работает | Установи нужную библиотеку в системный Python, например `pip install pillow` |

## Безопасность

- Агент может создавать и запускать файлы на твоём компьютере. Читай окна подтверждения и не отключай их без необходимости.
- Ключ хранится в `agent_config.json` открытым текстом. **Не публикуй этот файл и не отправляй другим.** Файл заблокирован для чтения самой моделью.
- Если ключ случайно попал в чужие руки, удали его в [Google AI Studio](https://aistudio.google.com/apikey) и создай новый.
